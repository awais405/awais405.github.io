# awais405.github.io

## Human-Like Traffic Simulator

This repository includes a Python script for simulating realistic human-like traffic to websites for testing purposes.

See [TRAFFIC_SIMULATOR_README.md](TRAFFIC_SIMULATOR_README.md) for complete documentation.

### Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run simulator
python traffic_simulator.py https://example.com --visits 10
```
